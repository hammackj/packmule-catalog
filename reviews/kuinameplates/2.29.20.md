# KuiNameplates 2.29.20 review

## What it does
KuiNameplates is a nameplate replacement framework. It has the core framework (`Kui_Nameplates`), a default layout (`Kui_Nameplates_Core`), an options UI (`Kui_Nameplates_Core_Config`), and textures and fonts (`Kui_Media`). It draws health bars, cast bars, auras, class powers, threat and target highlights, and plugins for fading, animation, tank mode, guild text, arena IDs and boss-mod integration. I read the addon code; the media files are only fonts and textures.

## Risky behaviours checked
- **Code from strings:** The prescan flagged 6 hits, and I checked each.
  - `CallbackHandler-1.0.lua:11` only localises `loadstring` (`local assert, error, loadstring = ...`). A search for `loadstring(` found no calls in any build. This is the standard Ace3 library header.
  - `LibSharedMedia-3.0.lua:18` has `local _G = getfenv(0)`. This is the standard library idiom for getting the global table and does not run code.
  - I found no `RunScript`, `setfenv`, `string.char`, `\x` escapes or base64-like blobs in any `.lua`, `.orig` or `.xml` file.
- **Gold, items, mail, trade, auction house, guild bank:** No `SendMail`, `DeleteCursorItem`, `PickupContainer` or `UseContainerItem` calls appear in the builds.
- **Chat, whispers and addon messages:** No `SendChatMessage`, `SendAddonMessage` or `BNSend*` calls appear. The addon sends no data to other players.
- **Macros, bindings, logout and popups:** No `SetBinding`, `CreateMacro`, `EditMacro`, `Logout` or `StaticPopup` use appears.
- **Links:** All URLs are the author's GitHub page in the `.toc`, library project pages in comments, or XML schema namespaces. There are no phishing links.
- **Non-addon file:** `classic/.../LibClassicDurations/classAbilities.lua.orig` is a leftover git merge-conflict file. It contains `<<<<<<< HEAD` markers and a spell-duration table header. Nothing in the prescan or `.toc` loads it, and it holds no executable payload. It is untidy packaging, not a threat.
- **Variants (classic and mists):** The differences are `.toc` files, `embeds.xml`, and the classic-only libraries `LibClassicDurations` and `LibClassicCasterino`. Both are well-known libraries that track combat-log spell data. They contain no messaging, string execution or item APIs.
- **Embedded instructions:** I found no text addressed to an AI or reviewer.

## Concerns
None. The stray `.orig` file is the only oddity.

VERDICT: PASS

## Codex

KuiNameplates 2.29.20 customizes nameplates: health and cast bars, auras, threat indicators, class resources, and appearance profiles. I reviewed the shared code, all variant differences, Classic libraries, and every prescan hit; static data tables were skimmed.

- **Gold, items, and destructive actions:** No mail, trade, auction, guild-bank transfer, item destruction, macro/keybinding manipulation, or forced logout behavior found.
- **Communication and privacy:** No outgoing chat, whisper, Battle.net, or addon-channel transmission found. `DispatchMessage` invokes local listeners ([messages.lua:108](/tmp/packmule-review-kuinameplates-ifdVp2/addon/builds/Kui_Nameplates-2.29.20/Kui_Nameplates/messages.lua:108)); boss-mod integration registers local callbacks. Debug/export output appears locally.
- **String execution:** All six prescan hits are benign duplicates across builds. `local assert, error, loadstring = assert, error, loadstring` declares an unused alias ([CallbackHandler:11](/tmp/packmule-review-kuinameplates-ifdVp2/addon/builds/Kui_Nameplates-2.29.20/Kui_Nameplates/lib/CallbackHandler-1.0/CallbackHandler-1.0.lua:11)). `local _G = getfenv(0)` retrieves globals for media handling ([LibSharedMedia:18](/tmp/packmule-review-kuinameplates-ifdVp2/addon/builds/Kui_Nameplates-2.29.20/Kui_Nameplates_Core/lib/LibSharedMedia-3.0/LibSharedMedia-3.0.lua:18)). Profile imports use `kui.string_to_table(input)`, not Lua execution ([main.lua:477](/tmp/packmule-review-kuinameplates-ifdVp2/addon/builds/Kui_Nameplates-2.29.20/Kui_Nameplates_Core_Config/main.lua:477)).
- **Links and deception:** All 25 prescan address hits are project/library references, font-tool credits, or XML namespaces. No phishing, impersonation, obfuscated payloads, or instructions addressed to AI/reviewers found.
- **Timers and settings:** Timers update displays, process spell tables, or expire cached observations. CVar changes control nameplate appearance and visibility.

Two non-security packaging concerns: Classic’s `classAbilities.lua.orig` contains `<<<<<<< HEAD` at [line 4](/tmp/packmule-review-kuinameplates-ifdVp2/addon/builds/Kui_Nameplates-2.29.20-classic/Kui_Nameplates/lib/LibClassicDurations/classAbilities.lua.orig:4), but is an unreferenced source backup, not an external executable. Mists’ [embeds.xml:7–8](/tmp/packmule-review-kuinameplates-ifdVp2/addon/builds/Kui_Nameplates-2.29.20-mists/Kui_Nameplates/lib/embeds.xml:7) references two absent libraries. These are packaging defects, with no malicious behavior identified.
