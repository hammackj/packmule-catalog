## Claude

**Satchel v0.2.4 review**

**What it does:** Satchel is a bag addon that shows all bags in one window. It also has a bank window, sorting, item locks ("protected" items), and sell-junk at vendors.

**Changes from v0.2.3 (CHANGES.diff, fully read):**
- **`Satchel.lua`, bank handling:**
  - It retries a few times with `C_Timer.After` when the bank tabs arrive late.
  - It adds a "Blizzard bank (buy bank slots)" button. The button hands `BankFrame` back to Blizzard's own window: it resets the `OnHide` script and the parent, then closes Satchel's bank window. It moves no items and sends nothing.
- **`Debug.lua`, `ns.ProbeBank`:** It reads bank layout through `C_Bank` and `C_Container` calls, plus global constants and the names of `BankFrame` children. It writes the result to the local `SatchelDB.debug.bankProbe`. It sends nothing and runs no strings.
- **`CHANGELOG.md` and `.toc`:** version bump only.

**Pre-scan hits:**
- `Satchel.lua:305-306`, `C_MerchantFrame.SellAllJunkItems`: this is Blizzard's sell-all-junk, called only when no locked greys exist. It is unchanged from v0.2.3.
- `Satchel.lua:321`, `UseContainerItem`: it sells grey, non-protected items one at a time at an open merchant. Each sale re-checks the slot, and the queue stops if the merchant closes. This is normal vendor-junk behaviour and unchanged.
- `Sort.lua:139-140`, `PickupContainerItem`: this swaps items between bag slots for sorting. It is unchanged and stays within the player's own bags.
- `luac.out` (28 KB), the one non-addon file: it is compiled Lua bytecode and is not listed in `Satchel.toc`, which loads only `Debug.lua`, `Data.lua`, `Sort.lua`, `Window.lua` and `Satchel.lua`. WoW never loads it. It looks like a stray `luac` build artifact, since `luac.out` is `luac`'s default output name. A string search of it found no URLs, `Send`, `Mail`, `Trade` or `loadstring`. It differs from the v0.2.3 copy, which fits a rebuilt artifact. It is harmless but sloppy to ship.

**Other checks across all `.lua`, `.toc` and `.xml` files:**
- No `loadstring`, `RunScript`, `load(`, `SendAddonMessage`, `SendChatMessage` or `SendMail`.
- No escaped-byte blobs, and no text aimed at a reviewer or an AI.
- I did not read every line of the unchanged code, which was already reviewed. I covered the diff, every pre-scan hit, and the greps above.

**Concerns:** Only the stray `luac.out`, which is inert. Nothing in the addon touches gold, mail, trade or chat, or sends data to other players.

VERDICT: PASS

## Codex

Satchel combines bags and bank storage into unified windows, remembers characters’ inventories and gold, sorts items, and sells vendor junk.

Reviewed the complete v0.2.4 diff, changed Lua files in full, every prescan hit, sorting logic, event and slash-command handlers, relevant item-button callbacks, and the bundled bytecode. Unchanged code was treated as previously reviewed.

- **Junk sales:** `Satchel.lua:305–306` calls `SellAllJunkItems()`; line 321 calls `UseContainerItem()` for queued sales. These follow explicit sell-button clicks (lines 339–354). The queue checks merchant presence, item identity, grey quality, value, and protection before selling. Normal vendor functionality.
- **Item movement:** `Sort.lua:139–140` calls `PickupContainerItem()` to stack or reorder items. Sorting starts from the Sort button (`Window.lua:467–468`), excludes protected items, and stops on invalid conditions. No item destruction or transfers to other players.
- **Bank changes:** `Satchel.lua:139–148` restores Blizzard’s bank window; lines 229–267 retry bank detection and collect diagnostics. These timers do not purchase slots, withdraw gold, or transfer items.
- **Stored player data:** `Debug.lua:166–214` records bank layout and character name in local `SatchelDB` saved variables. Inventory and gold snapshots likewise remain local (`Data.lua:16–74`). No outbound chat, Battle.net, addon-message transmission, or incoming message handlers were found.
- **Commands and code execution:** `/satchel` changes display settings and local records (`Satchel.lua:537–596`). No string execution, hidden loaders, malicious macros, binding changes, logout calls, or phishing behavior were found.
- **Unusual file:** `luac.out` is Lua 5.1 bytecode. Its complete disassembly matches `Satchel.lua` after normalizing source paths and memory addresses. It is absent from the loading manifest (`Satchel.toc:10–14`), indicating a redundant build artifact.
- **Reviewer manipulation:** No reviewer-directed instructions were found. The changelog’s AI coauthor attribution is ordinary metadata.

No malicious behavior or unresolved security concern identified.

VERDICT: PASS (nothing malicious)
