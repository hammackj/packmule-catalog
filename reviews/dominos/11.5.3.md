# Dominos 11.5.3 review

**What it does:** Dominos is an action bar addon. It replaces and rearranges the Blizzard action, pet, stance, bag, menu and micro-menu bars. The extra modules add a cast bar, a progress bar and a mirror timer. It also bundles Ace3, LibKeyBound, LibDBIcon and LibSharedMedia, and Masque_Dominos supplies skins.

**Risky behaviours checked**

- **Code from strings:** both prescan hits are harmless.
  - `AceAddon-3.0.lua:49` only localises `loadstring` into a local variable. I found no call to `loadstring`, `load` or `RunScript` anywhere under `builds/`.
  - `LibSharedMedia-3.0.lua:18` is `getfenv(0)`, which just fetches `_G`. This is standard library code.
- **Key bindings:**
  - `Dominos.lua:324` is `MigrateBindings`. It remaps the player's existing `CLICK DominosActionButtonN:LeftButton` bindings to `:HOTKEY`, and nothing else. The bindings it writes are only Dominos' own button clicks.
  - `bars/actionBar/bindings.lua:49` and `core/bindableButton.lua:44,52` set or clear the player's key binding for a Dominos button. This is the normal key-binding feature.
  - `LibKeyBound-1.0.lua:605,627` is the standard keybinding-mode library, which binds or unbinds a key when the player presses it.
  - None of these bind keys to mail, trade, auction, logout or chat actions.
- **Gold and item movement, item deletion, chat, whispers, addon messages, Battle.net:** a grep for `SendChatMessage`, `SendAddonMessage`, `SendMail`, `DeleteCursorItem`, `Logout`, `ForceQuit`, `C_BattleNet`, `CreateMacro`, `EditMacro` and `RunMacro` found nothing in the code.
- **Obfuscation:** the only escaped bytes (`\195\169` and similar) are UTF-8 accented characters in the French and German localisation strings. I saw no base64-like blobs or unreadable code.
- **Links:** every URL is an XML schema namespace, a library doc link, a translator credit, or a Masque_Dominos project page (GitHub, CurseForge, Wago, WoWInterface, Discord). None is a popup or a chat link.
- **Hooks:** `hooksecurefunc` appears only on Blizzard UI frames such as the bags, micro menu, talking head, queue status and totem bar. It is used for repositioning.
- **Non-addon files:** I found no executables or scripts (`.exe`, `.sh`, `.bat`, `.ps1`, `.py`, `.dll`, `.js`). `AGENTS.md` is a project note about AI use policy, written for contributors. It contains no instructions aimed at a reviewer or an AI that I would treat as injected.

**Coverage:** the file listing showed only 100 of 213 files. I read the prescan hits in context and grepped the whole tree for the dangerous APIs, but I did not read every file line by line.

**Concerns:** none.
