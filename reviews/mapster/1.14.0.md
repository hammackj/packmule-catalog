# Mapster 1.14.0 security review

**What it does:** Mapster is a world map addon. It makes the map movable, scalable and fadeable, and adds a coordinates display and an options panel. It also has a FogClear module that draws the unexplored map art, using texture file IDs from a data table. It stores its settings in `MapsterDB`.

## Risky behaviour checked

- **Code from strings.** The only prescan hit is `Libs/AceAddon-3.0/AceAddon-3.0.lua:49`: `local loadstring, assert, error = loadstring, assert, error`. This is a local alias in the standard Ace3 library. A repo-wide grep finds no other `loadstring`, `RunScript` or `load(`, so nothing executes strings.
- **Gold, items, mail, trade, auction house, guild bank and item deletion.** None of these APIs appear anywhere in the addon.
- **Chat, whispers and addon messages.** There are no `SendChatMessage`, `SendAddonMessage` or Battle.net calls. The addon doesn't talk to other players.
- **Player data.** The Coords module reads the player's map position (`Coords.lua:167`) and only shows it locally in a font string. It isn't sent anywhere.
- **Macros, bindings and logout.** No `SetBinding`, `CreateMacro`, `EditMacro` or logout calls.
- **Phishing and popups.** No custom popups or URLs in the addon's own code. The 18 "link" hits in the prescan are XML schema namespace URLs and wowace.com documentation comments in library headers.
- **Global access (`_G[...]`).**
  - In the Ace libraries it is used for standard purposes: LibStub registration, AceHook hooks and slash-command registration.
  - In `BattleMap.lua` and `GroupIcons.lua` it only hides frames or looks up unit frames. Both files are commented out of the `.toc`, so they don't load.
- **CVar and secure frame changes.**
  - `Coords.lua:117-118` turns off Blizzard's built-in coordinate display.
  - `Config.lua:53` sets the `mapFade` CVar from the options checkbox.
  - `Mapster.lua:51-60` (`purgeKey`) removes `WorldMapFrame` from `UIPanelWindows`. This is a known technique in map addons for making the map movable, and it isn't harmful.
- **Data files.** `FogClearData.lua` and `FogClearDataForever.lua` are plain tables mapping map art IDs to texture file ID strings. A pattern search for function calls or non-data lines found only the header comment and the table assignment. I saw no embedded code.
- **Obfuscation and AI-directed text.** None found. The code is readable and the comments are ordinary copyright and technical notes.
- **Non-addon files.** The zip contains only `.lua`, `.xml`, `.toc`, `.tga` textures and a changelog. There are no executables or scripts.

I read the addon's own Lua files in full: `Mapster.lua`, `Config.lua`, `Coords.lua`, `Scaling.lua` and `FogClear.lua`. The bundled Ace3, LibStub and LibWindow libraries were checked by targeted searches of the risky APIs, not read line by line.

## Codex

Mapster 1.14.0 customizes the world map’s position, scale, fading, player arrow, coordinates, and unexplored-area artwork. I read all code under `builds/`, including bundled libraries and inactive modules, skimmed both fog-data tables, and checked every prescan hit.

Paths below are relative to `builds/Mapster-1.14.0/Mapster/`.

- **Code from strings:** `Libs/AceAddon-3.0/AceAddon-3.0.lua:49` declares `local loadstring, assert, error = loadstring, assert, error`. The `loadstring` alias is never called. No hidden loaders, decoded payloads, or remotely supplied code found.
- **Gold, items, and mail:** No mail sending, money transfers, trading, guild-bank withdrawals, auctions, or destructive operations found. `AceGUIWidget-EditBox.lua:81–100` reads dragged item/spell/macro information and calls `ClearCursor()`; this clears the cursor without destroying items.
- **Messages and privacy:** `Libs/AceEvent-3.0/AceEvent-3.0.lua:46` assigns `AceEvent.SendMessage = AceEvent.messages.Fire`, an internal callback dispatcher. `Libs/AceConsole-3.0/AceConsole-3.0.lua:43` uses `frame:AddMessage(...)` for local display. No outgoing chat, whispers, Battle.net messages, or addon-channel transmissions found. Coordinates are displayed locally (`Coords.lua:167–181`).
- **Bindings, macros, and timers:** The keybinding widget only captures user input and fires a callback (`Libs/AceGUI-3.0/widgets/AceGUIWidget-Keybinding.lua:82–84`). No macro/binding modifications or forced logout found. AceDB’s `PLAYER_LOGOUT` handler cleans saved settings; the slider’s timer refreshes displayed text.
- **Links and phishing:** All 18 prescan address hits are benign: 14 XML namespace/schema headers, library metadata at `Libs/LibStub/LibStub.toc:5`, and documentation URLs at `Libs/LibWindow-1.1/LibWindow-1.1.lua:5–7`. Additional links are project/localization references. No account scams or deceptive prompts found.
- **Package contents:** Only Lua, XML, TOC, Markdown, and nine valid TGA textures are present. No external executables, shell scripts, suspicious appended texture payloads, or AI/reviewer-directed instructions found.

No malicious behavior or unresolved security concern identified in the reviewed contents.

VERDICT: PASS (nothing malicious)
