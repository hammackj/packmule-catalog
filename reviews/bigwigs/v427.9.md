# BigWigs v427.9 security review

## What it does
BigWigs is a boss-encounter addon. It provides timers, alerts, bars and messages, plus an options UI. The package contains the Loader, Core, Options, Plugins, Tools and the standard Ace/Lib* libraries. It also has audio files, a changelog and license text.

## Risky behaviours checked

**Bag items (`Tools/Keystones.lua:1044-1065`)**
- When the player opens the Mythic+ keystone receptacle, and the `autoSlotKeystone` option is on, it finds an item link containing `Hkeystone`.
- It then calls `PickupContainerItem` followed by `SlotKeystone()`.
- This only runs on `CHALLENGE_MODE_KEYSTONE_RECEPTABLE_OPEN` and only when the keystone matches the current dungeon.
- It only moves the player's own keystone into the keystone UI. It does not touch mail, trade or the auction house. Not a problem.

**Chat and whispers**
- `BossPrototype*.lua` sends SAY/YELL text such as "spell on <me>". This is the player-enabled boss "say" feature. The text comes from boss spell names and is not user-addressed or a link.
- `Options.lua:1133-1136` posts the boss ability list to a channel the player picks, from a UI button.
- `AutoInvite.lua:94-110` and `:258` whisper "my group is full" in reply to someone who whispered a configured invite keyword. It also invites that sender. This is an opt-in feature and the reply is a fixed localized string.
- `AutoReply.lua:223-248` and `:363` send "[BigWigs] …" whispers and Battle.net replies to people who whispered the player during a boss fight. Replies are throttled and use fixed localized text. It is a standard opt-in auto-reply feature.
- `LibSink-2.0.lua:437-443` is a stock library output to a chosen channel.
- None of this contains links, scams or impersonation.

**Addon messages**
- The prefixes are `BigWigs`, `LibDRBLT` (durability), `LibKS` (keystone level), `LibLTNC` (latency), `LibSpec` (specialization), `Transcriptor`, and DBM-compatible timers and break timers.
- They go to group, raid, instance or guild channels, and carry only version, sync, keystone, spec, durability and latency data. This is normal group-sync behaviour.
- No gold, character-list or account data is sent.

**Code from strings**
- The "Runs code from strings" hits are false positives. `Loader.lua:825` is a local function named `load` that wraps `LoadAddOn` for the addon's own modules. `getfenv(0)` in LibSharedMedia is standard.
- A grep for `loadstring`, `RunScript`, escaped-byte blobs, `SetBinding`, `DeleteCursor`, `SendMail`, `AcceptTrade`, logout and clipboard calls returned no matches.

**Links**
- The links are GitHub, CurseForge and the BigWigs Discord (`Options.lua:236`, shown as plain text `discord.gg/jGveg85`). These are the project's own or library-credit links.

**Non-addon files**
- A search for executables and scripts (`exe`, `sh`, `bat`, `ps1`, `dll`, `py`, `js`, `jar`, `cmd`, `vbs`) found none.
- The package holds Lua, XML and TOC files, `.ogg` sounds, license text and the changelog.
- The glob listing was truncated at 100 of 413 files, so I didn't view every file. The grep and extension searches covered the whole tree.

## Concerns
None. I found no text addressed to a reviewer or AI, and no obfuscation, gold or item movement, or phishing.

VERDICT: PASS

## Codex

BigWigs provides boss warnings, encounter timers, sounds, and group coordination tools. **No malicious behavior was confirmed in the paths inspected, but the required full-code review is incomplete.** I inventoried 173 Lua files and searched across them; I did not read every file end to end.

Paths below are relative to `builds/BigWigs-v427.9/`.

- **Items and gold:** `BigWigs/Tools/Keystones.lua:1065` calls `PickupContainerItem`, immediately followed by `SlotKeystone()`. This runs when the matching dungeon’s keystone receptacle opens, respects `autoSlotKeystone`, and prints a notice. No mail, trade, auction, gold-transfer, or item-destruction calls surfaced in the searches.
- **Chat and Battle.net:** Both boss prototypes gate SAY/YELL warnings and countdowns on encounter settings (`BigWigs_Core/BossPrototype.lua:5019`; classic counterpart `:4748`). Auto-invite replies require configured keywords (`BigWigs/Tools/AutoInvite.lua:89`). Auto-reply starts with `disabled = true` and throttles replies to incoming whisperers (`BigWigs_Plugins/AutoReply.lua:13`, `:348`). Ability-list broadcasts require a button click (`BigWigs_Options/Options.lua:1812`). LibSink’s channel sender is generic configurable output, not evidence of unsolicited spam.
- **Addon messages:** Checked payloads contain versions, encounter synchronization, boss whispers, alternate power, durability, latency, specialization/talents, and keystone/rating information. Recipients are group or guild channels—not a hard-coded collector. Examples: `BigWigs_Core/Core.lua:214`, `BigWigs/Libs/LibKeystone/LibKeystone.lua:127`, and `BigWigs/Libs/LibSpecialization/LibSpecialization.lua:672`.
- **String execution and bindings:** `BigWigs/Loader.lua:825` defines a local `load` wrapper around `LoadAddOn`; `getfenv(0)` retrieves globals. Profile imports deserialize CBOR rather than evaluate Lua (`BigWigs_Options/Sharing.lua:839`). The macro at `BigWigs/Tools/Keystones.lua:1712` opens a whisper editor on click. Optional bindings open the keystone viewer or start a pull countdown.
- **Links and packaged files:** Inspected links concern project support, distribution, documentation, or asset attribution. No external executable/script files, suspicious encoded blobs, or reviewer-directed instructions were found by the checks performed.
- **Notable behavior:** “Pretend I'm using DBM” deliberately falsifies version-check replies, but is explicitly labeled and disabled by default (`BigWigs/Locales/enUS.lua:197`; `BigWigs/Loader.lua:1270`, `:1717`).

The remaining boss, UI, and library code needs complete inspection before Packmule can approve this first review.

VERDICT: UNSURE
