## Claude

# OmniCC 11.2.8 review

**What it does:** OmniCC puts numeric cooldown countdown text on action buttons and other cooldown frames. It hooks the Blizzard Cooldown frame methods (`SetCooldown`, `SetCooldownDuration`, `Clear`, `SetHideCountdownNumbers`) with `hooksecurefunc` in `OmniCC/core/cooldown.lua:626-633`. It then draws timers and optional finish effects (pulse, shine, flare, alert). `OmniCC_Config` is an AceConfig options UI. Settings are stored in the `OmniCCDB` and `OmniCC4Config` saved variables.

**What I read:** all of OmniCC's own code, including `main.lua`, `core/cooldown.lua` and the toc, and I grepped the whole tree. I did not read each bundled library line by line. They are the standard Ace3, LibStub, CallbackHandler and LibSharedMedia libraries, and the greps found nothing unusual in them. No executables or scripts are in the zip. The only non-addon files are README, CHANGELOG, LICENSE and a `.tga` texture.

**Risky behaviour checked**
- **Prescan "runs code from strings" hit:** `LibSharedMedia-3.0.lua:18` is `local _G = getfenv(0)`. This is the standard idiom for getting the global table. It does not run any string, so it is not a problem.
- **loadstring / RunScript / load / setfenv:** none found anywhere.
- **Gold, items, mail, trade, auction house, guild bank, item deletion:** no such API calls.
- **Chat, whispers, Battle.net, SendAddonMessage:** none. The addon sends no messages. Its only output is a local `print` of the version at `main.lua:22`.
- **Links:** the prescan hits are XML namespace URLs and wowace/sourceforge URLs in library comments. The README links are only to the author's pages. The addon has no popups, link dialogs or URL-opening calls.
- **Slash commands:** `/omnicc` and `/occ` open the options frame, print the version, or toggle Blizzard's cooldown text. The toggle calls `C_UI.Reload()` (`main.lua:29`). That is a user-initiated UI reload, not a logout.
- **Key bindings and macros:** none changed.
- **`_G` access:** `main.lua:79` looks up `<name>Icon` and `<name>IconTexture` on button frames to find their icon textures. `main.lua:89` exports `_G.OmniCC`. Both are normal.
- **Other `securecallfunction` hits:** `CallbackHandler-1.0.lua:10,19` is stock library code.
- **Obfuscation or text aimed at a reviewer:** none seen.

**Concerns:** none.

VERDICT: PASS
