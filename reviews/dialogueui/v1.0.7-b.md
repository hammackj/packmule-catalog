## Claude

**DialogueUI v1.0.7-b: no malicious behaviour found**

**What it does:** DialogueUI replaces Blizzard's quest, gossip and book dialogue windows with a themed UI. It adds a quest-NPC chat log, a camera and zoom effect during dialogue, TTS narration, quick-slot quest-item buttons, settings and keybinding options, and compatibility shims for other addons (Pawn, Rematch, Wholly, BtWQuests, VoiceOver and others). The `.toc` lists only the addon's own Lua and XML files. It declares SavedVariables `DialogueUI_DB` and `DialogueUI_Saves`.

**Risky behaviours checked**
- **Files in the zip:** The zip contains only `.lua`, `.xml`, `.toc`, textures (`.png`, `.tga`, `.blp`) and `Art/GameAssets/Manifest.txt`. A search for `.exe`, `.dll`, `.bat`, `.sh`, `.ps1`, `.py`, `.js` and similar found none.
- **Prescan hits:** All 23 are XML schema URLs, `warcraft.wiki.gg` links and GitHub or CurseForge links in code comments. None of them is user-facing, and none is a phishing popup or a chat link.
- **Hidden code:** A search for `loadstring`, `RunScript`, `load(`, `setfenv`, escaped bytes and base64-like blobs of 120 or more characters found nothing. `_G[...]` is used only to look up tooltip lines and font objects (`API.lua`, `FontUtil.lua`, `ThemeUtil.lua`).
- **Messaging:** A search for `SendChatMessage`, `SendAddonMessage`, `C_ChatInfo`, `BNSend` and `RegisterAddonMessagePrefix` found nothing. The only chat output is local. `NameplateGossip.lua:37` calls `ChatFrame1:AddMessage` to show NPC text in the player's own chat frame. `UITemplates.lua:1502` calls `ChatEdit_InsertLink` on a modified click, which is the standard shift-click link insertion.
- **Gold and items:** A search for mail, trade, auction, guild bank, `PickupPlayerMoney`, `DeleteCursorItem` and `UseContainerItem` found nothing.
- **Macros and bindings:**
  - `Code/Dialogue/ActionButton.lua` builds secure buttons with fixed macro text: `/use item:<id>` (line 215), `/use <name>` (line 203) and `/equip item:<id>` (line 254).
  - The item IDs come from quest reward and quest item buttons.
  - The buttons run on the player's click, or on the player's own interaction key, via `SetOverrideBindingClick` (line 106).
  - Bindings are cleared on release and on entering combat (lines 36–51, 114–129).
  - `SetPressToCommand` (line 76) has no caller, so it is unused.
  - `Settings_Keybinding.lua` and `Utility/Keybindings.lua` only handle rebinding the addon's own actions.
  - No `CreateMacro` or `EditMacro` calls exist.
- **CVars and console:** `Camera.lua` changes camera CVars and runs `ConsoleExec("pitchlimit N")`, which is camera-only. It backs up the old values and restores them (`BackupAndSetCVar`). The only logout reference is a comment about the AFK-logout camera state (line 251).
- **StaticPopup:** It is used only to show or close Blizzard's own quest confirmation dialogs (`UITemplates.lua:162`, `API.lua:3450`).
- **Data files:** Locale files and gossip and item tables are plain data with no embedded code. A search for text aimed at an AI or reviewer found none.

**Concerns:** None. I read the flagged files in full or in context. I did not read the whole code base line by line. The ~120 remaining files, including the UI layout code and large data tables, were covered by pattern searches for the harms listed above and by skimming.

VERDICT: PASS

## Codex

DialogueUI replaces quest, NPC dialogue, and book interfaces, adding camera effects, reward displays, keyboard controls, and text-to-speech.

- **Gold and items:** Quest completion uses `GetQuestReward(rewardChoiceID)` ([API.lua:1113](/tmp/packmule-review-dialogueui-u8dh56/addon/builds/DialogueUI-1.0.7-b/DialogueUI/API.lua:1113)). Optional automatic turn-ins are restricted to selected quests. Ordinary gold-cost interactions display the cost and require confirmation ([DialogueUI.lua:2087](/tmp/packmule-review-dialogueui-u8dh56/addon/builds/DialogueUI-1.0.7-b/DialogueUI/Code/Dialogue/DialogueUI.lua:2087)). No mail transfers, auction transactions, guild-bank withdrawals, or item/mail destruction calls were found.
- **Macros and bindings:** Item buttons construct `"/use item:"..itemID` and `"/equip "..item`, activated through clicks or temporary hotkeys ([ActionButton.lua:215](/tmp/packmule-review-dialogueui-u8dh56/addon/builds/DialogueUI-1.0.7-b/DialogueUI/Code/Dialogue/ActionButton.lua:215), [254](/tmp/packmule-review-dialogueui-u8dh56/addon/builds/DialogueUI-1.0.7-b/DialogueUI/Code/Dialogue/ActionButton.lua:254)). These support displayed quest/reward items; no harmful macro commands were found.
- **Communication and privacy:** No outgoing chat, whisper, Battle.net, or addon-message calls were found. `ChatEdit_InsertLink(link)` follows the player’s modified click and inserts a quest-item link into the chat editor ([UITemplates.lua:1491](/tmp/packmule-review-dialogueui-u8dh56/addon/builds/DialogueUI-1.0.7-b/DialogueUI/Code/Dialogue/UITemplates.lua:1491)). NPC chat display and narration are local features.
- **String execution:** No `loadstring`, `RunScript`, or obfuscated executable payload was found. `ConsoleExec("pitchlimit "..pitch)` controls camera pitch using a calculated number ([Camera.lua:500](/tmp/packmule-review-dialogueui-u8dh56/addon/builds/DialogueUI-1.0.7-b/DialogueUI/Code/Camera.lua:500)). Logout event handling restores camera settings; it does not initiate logout.
- **Prescan and package:** All 23 prescan hits are documentation references: 14 XML schema declarations, eight localization comments, and one texture-workaround comment. No phishing destination, reviewer-directed instruction, or standalone executable/script was identified.

**Concern:** The required complete reading of all code under `builds/` was not completed. The inspected paths and package-wide searches revealed no malicious behavior, but they are insufficient to certify this first review as complete.

VERDICT: UNSURE
