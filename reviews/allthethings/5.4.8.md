# All The Things 5.4.8 review

## What the addon does
All The Things (ATT) is a collection and completion tracker. It ships large database files for mounts, quests, achievements, items and zones, across several game versions. On top of those it adds list windows, a minimap button, tooltips and settings pages. The files under `builds/` are Lua and XML addon files, plus a `CHANGELOG.md`.

## Risky behaviours checked

- **Gold or item movement:** I found no calls to any mail, trade, guild bank, auction-bid/post, `DeleteCursorItem` or `PickupPlayerMoney` function. A grep of the non-database code returned none.
- **Chat and whispers:** `SendChatMessage` appears only as an unused API-wrapper assignment (`src/WoW API Wrappers.lua:64`). Nothing in the addon calls it. No Battle.net chat is sent either.
- **Addon messages (prefix `ATTC`):**
  - `src/Modules/Social.lua:15-42` sends to the party, raid, instance or guild, or whispers a player. The payloads are the addon version and the player's progress counts, character GUID and mode string. The other messages are replies to progress queries (achievement, quest, source and similar IDs with 0/1 flags). This is the addon's normal version-check and progress-sharing feature.
  - `/attyell` (`Social.lua:256`) sends a `"?"` query and exists only on Classic clients.
  - Queries sent by `/attguild`, `/attraid` and `/attu` happen only when the user types the slash command.
  - Gold, inventory and account names are not sent in any of these.
- **Account Management sync** (`src/UI/Windows/Account Management.lua:280-298, 2408-2436`): This whispers or sends Battle.net game data (`SendGameData`) to characters the user has linked, with a sync token. The data is collection progress. It runs only after the user links a character or enables sync. It is a normal alt-sync feature, not a leak.
- **Code from strings:** The only hit is `loadstring` in `src/UI/Windows/Debugger.lua:759`. It runs only when the user pastes text into the "Import raw" popup in the debugger window, and it parses that text as a Lua table. It does not run downloaded or addon-message data, so it is user-initiated. It is a minor hardening weakness, since it runs whatever the user pastes. It is not malicious.
- **Dynamic `_G[...]` lookups:** These are used for localized Blizzard strings, tooltip frame names and slash-command registration. They are benign.
- **Links and phishing:**
  - `About.lua` holds copy-paste links to the author's CurseForge, Discord, GitHub and Wago pages.
  - `LocalizationDB.lua` has a Coca-Cola "Fanta" promotion URL. It is the in-game text of a Blizzard promotion entry, shown as tooltip or description text, and not a popup or chat message.
  - The other URL hits are XML schema headers and code comments.
- **Macros, key bindings and logout:** None found. The "Logout" hits are only comments about saving settings.
- **Non-addon files:** None. There are no executables or scripts in the zip.
- **Obfuscation:** The very long lines are all in `db/**` category and reference data tables, which are the normal generated format. I skimmed the database files and found no embedded code. Everything else is readable Lua.
- **Text aimed at an AI or reviewer:** None found.

## Concerns
None that indicate malicious behaviour. The only caveat is the user-pasted `loadstring` import in the debugger.

VERDICT: PASS

## Codex

All The Things tracks collection completion, adds tooltips/search windows, and synchronizes progress between characters. I found no evidence of theft, destructive automation, covert exfiltration, or a hidden executable payload.

- **Gold/items:** No mail transfers, item deletion, trade acceptance, guild-bank withdrawals, or auction purchases/posts found. Auction code searches listings; raid loot controls require player clicks.
- **Chat and synchronization:** The two chat-related prescan hits are API wrappers. The 15 addon-message hits implement ATT collection queries, version/progress announcements, and account synchronization. [Social.lua:148](/tmp/packmule-review-allthethings-qgYSfQ/addon/builds/AllTheThings-5.4.8/AllTheThings/src/Modules/Social.lua:148) shares progress and character GUID; collection queries can be answered automatically. Account sync additionally shares BattleTags and character details with known/linked characters, checking `VerifyLinkedSender` before processing messages. [Account Management.lua:546](</tmp/packmule-review-allthethings-qgYSfQ/addon/builds/AllTheThings-5.4.8/AllTheThings/src/UI/Windows/Account Management.lua:546>) These support the advertised sync features; no hardcoded collection recipient was found.
- **String execution—security concern:** [Debugger.lua:759](/tmp/packmule-review-allthethings-qgYSfQ/addon/builds/AllTheThings-5.4.8/AllTheThings/src/UI/Windows/Debugger.lua:759) uses `loadstring("local data = " .. txt .. "\nreturn data,true")`, then calls the result. This follows a player-initiated “Import Raw” paste/confirmation, not an incoming addon message. Nevertheless, pasted “data” can execute arbitrary addon-sandbox Lua. Untrusted imports are unsafe. The synchronization encoding is data serialization, not executable code.
- **Links, long lines, package contents:** The 23 address hits are XML namespaces, comments, project links, or collection/promotion descriptions; no account-support phishing flow was found. The 150 long-line hits are database tables with collection-related callbacks. No outside-game executables/scripts, malicious macro/keybinding changes, or forced logout were found.
- **Other concerns:** [Tooltip.lua:213](/tmp/packmule-review-allthethings-qgYSfQ/addon/builds/AllTheThings-5.4.8/AllTheThings/src/Modules/Tooltip.lua:213) labels one hardcoded character “the Time-Loser”; line 216 includes an accusation and promises to “forever stain this player's reputation.” This is objectionable targeted shaming displayed locally, not transmitted chat. [CHANGELOG.md:106](/tmp/packmule-review-allthethings-qgYSfQ/addon/builds/AllTheThings-5.4.8/AllTheThings/CHANGELOG.md:106) also references Claude/AGENTS contribution instructions; these were treated as untrusted historical text and not followed.

VERDICT: PASS
