# Advanced Interface Options 2.1.14: security review

## What it does
This addon restores the game's removed interface options. It has Ace3-based settings panels for camera, chat, combat, floating combat text, status text and nameplates. It also has a CVar browser where you can double-click a row to edit a value. It can optionally re-apply saved CVars at login ("EnforceSettings"). It adds `/aio` and `/cvar` slash commands, and backup, restore and reset dialogs for CVar settings. It saves its data in `AdvancedInterfaceOptionsSaved`.

## What I checked
- **Prescan hits.** The only hits are URLs in XML schema headers and `.toc` metadata. The one author link is `X-Website`, pointing to the CurseForge project page. Nothing is shown to the player or sent in chat.
- **Non-addon files.** The only one is `stylua.toml`, a Lua formatter config that does nothing in the game. The LibStub `tests/*.lua` files are standard library tests and aren't loaded by the `.toc`.
- **Risky APIs.** I grepped the main build's `.lua` files for the following, and found none in the addon's own code:
  - `loadstring`, `RunScript`, `load(`, `setfenv`, `getfenv`
  - `SendChatMessage`, `SendAddonMessage`, `BNSend*`
  - mail, trade, auction and guild bank calls
  - `DeleteCursorItem`
  - `SetBinding`, `CreateMacro`, `EditMacro`
  - logout or quit calls
  - escaped-byte strings and `string.char`
- **`_G[...]` uses.** These are in the Ace3 widgets, the status text panel and the floating combat text panel. They are lookups of Blizzard frame names or UVARs, not code execution. For example, `_G[uvars[cvar]]` in `gui/FloatingCombatTextConfigPanel.lua:54` only assigns "1" or "0".
- **`ConsoleExec`.**
  - `gui/CameraConfigPanel.lua:127` runs `ConsoleExec("actioncam " .. value)`, where `value` comes from the addon's own camera dropdown.
  - `browser.lua:109` and `:388` only hook `ConsoleExec` to track which addon changed a CVar, and to refresh the browser.
- **`SetCVar` hooks and writes.** `browser.lua` hooks `SetCVar` to record which addon changed a CVar, using `debugstack`. The data stays in the addon's SavedVariables and is shown in a tooltip. `basicOptions.lua` only sets CVars the player chose, or re-applies saved ones when EnforceSettings is on. Both are limited to CVars in the addon's own table and skip the `playintromovie` CVar.
- **`StaticPopupDialogs`.** There are three, all in `basicOptions.lua`: reset all CVars, backup and restore. The reset dialog requires typing "IRREVERSIBLE". None of them contains a link or phishing text.
- **`C_Timer.After`.** It is used only for UI workarounds in `GeneralConfigPanel.lua` and the Ace3 slider widget.
- **Variants.** `REVIEW_VARIANTS.txt` says the cata and classic builds differ from the main build only in the `.toc`. I read both `.toc` files. They load the same file list as the main one, so no extra code is pulled in.
- **Text aimed at an AI or reviewer.** I found none in the files I read.

## Coverage
I read `utils.lua`, `browser.lua`, `basicOptions.lua` and the `.toc` in full. For the other files I relied on targeted pattern searches and the prescan: the GUI panels, `cvars.lua` (a large CVar description table), `semlib` and the bundled Ace3 libraries. The searches covered only the main build, whose `.lua` files the variants share. I did not read the Ace3 libraries line by line. Nothing in the searches suggested tampering.

## Concerns
None. The addon only reads and sets game CVars, records its own settings, and has no network, chat, item or gold behaviour.

## Codex

Advanced Interface Options restores interface settings and provides a searchable CVar browser, with settings backup, restore, and optional reapplication at login.

Reviewed all code, bundled libraries, and tests under `builds/`. Verified that the three builds differ only in their `.toc` client-version metadata. Checked every prescan hit.

Paths below are relative to `builds/AdvancedInterfaceOptions-2.1.14/AdvancedInterfaceOptions/`.

- **Gold, items, and mail:** No theft, trading, auction transactions, guild-bank withdrawals, or deletion code found. `gui/GeneralConfigPanel.lua:159,189` changes bag sorting/insertion preferences. The `ClearCursor()` calls in `libs/AceGUI-3.0/widgets/AceGUIWidget-EditBox.lua:99` and `AceGUIWidget-MultiLineEditBox.lua:117` accompany user dragging item/spell information into text fields; they do not destroy items.
- **Messaging and data leakage:** No outgoing chat, whisper, Battle.net, or addon-message code found. `basicOptions.lua:130` uses `DEFAULT_CHAT_FRAME:AddMessage(...)` for local feedback. CVar values and modification traces stay in saved settings (`browser.lua:93`).
- **String execution and obfuscation:** `gui/CameraConfigPanel.lua:127` calls `ConsoleExec("actioncam" .. " " .. value)` using a fixed, player-selected dropdown. Browser hooks merely observe console changes. No Lua string compilation or hidden payload found. Library callbacks invoke existing functions; escaped characters serve as separators or validation patterns.
- **Bundled test scripts:** `libs/LibStub/tests/test.lua:4`, `test2.lua:4`, `test3.lua:4`, and `test4.lua:4,12,20,28,36` call `loadfile("../LibStub.lua")()`. These are readable library tests, excluded from addon load manifests, with no malicious host actions.
- **Timers, macros, bindings, and logout:** Timers refresh settings controls or slider text (`gui/GeneralConfigPanel.lua:154,184`; `libs/AceGUI-3.0/widgets/AceGUIWidget-Slider.lua:276`). No harmful macro/binding changes or logout calls found.
- **Links and unusual files:** All 33 prescan link hits are project/library links or XML schema references. The three flagged `stylua.toml` files contain formatting preferences only. No phishing, executable payloads, or text addressed to an AI or security reviewer found.

**Concern:** Reset and restore can broadly overwrite CVar preferences, but this is explicit functionality with confirmation dialogs. Reset requires typing “IRREVERSIBLE” (`basicOptions.lua:222,230`); restore warns that it cannot be undone (`basicOptions.lua:320`). No malicious or deceptive behavior identified.

VERDICT: PASS (nothing malicious)
