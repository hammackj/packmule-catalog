# Bartender4 4.18.4 review

**What it does:** Bartender4 is a long-standing action bar replacement addon. It rearranges and skins the action bars, pet bar, stance bar, bag bar, micro menu and so on, and has an options UI built on the Ace3 libraries. The `libs/` folder holds the usual bundled libraries: Ace3, LibActionButton, LibKeyBound, LibSharedMedia, LibDualSpec, LibStub and others.

**Files:** The zip contains only Lua, XML, TOC, locale files, a changelog and a library README and LICENSE. I found no executables or scripts (no .exe, .dll, .sh, .bat, .py, .js, .ps1 or similar).

## Risky behaviours checked

- **Code from strings.**
  - `AceAddon-3.0.lua:49` only localises `loadstring`. A repo-wide grep found no call to it, nor any `RunScript` or `load(`.
  - `LibSharedMedia-3.0.lua:18` is `local _G = getfenv(0)`, the standard global-table lookup.
  - The `_G[...]` hits build names for frames, binding labels and slash commands, such as `"ActionButton"..i`. They are not used to run code.
  - The long string attributes in `Bartender4.lua:154-211` are Blizzard secure-snippet handlers. They are Lua text stored as frame attributes and run in the secure environment. They contain no dynamic or downloaded content.
- **Key bindings and macros.**
  - All 16 hits are ordinary action bar behaviour. They bind keys to the addon's own buttons, such as `CLICK BT4Button%d:Keybind` and `SetBinding(key, "SHAPESHIFTBUTTON%d")`. They also clear bindings when a button is rebound.
  - In `Bartender4.lua:157-205`, the pet-battle and vehicle drivers temporarily point the player's own action bar keys at `ACTIONBUTTON` or `OverrideActionBarButton` while in a pet battle or vehicle. They then call `ClearBindings`.
  - The LibKeyBound and LibActionButton hits are the standard keybind-mode code.
  - I found no `CreateMacro` or `EditMacro`.
- **Mail, trade, auction, guild bank, item deletion.** Grep found no use of `SendMail`, `PickupPlayerMoney`, `TakeInboxMoney`, `InitiateTrade` or `DeleteCursorItem`. Nothing here touches gold or items.
- **Chat and addon messages.** No `SendChatMessage`, `SendAddonMessage` or `BNSend*` calls, so there is no data leak and no spam channel.
- **Logout and quit.** No `Logout` or `Quit` calls.
- **Obfuscation.** I found no escaped-byte blobs, `string.char` assembly or base64-like data. The code I read is plain and readable.
- **Links.** The only URLs are the author's own pages, in `Options/Options.lua:341` and the locale files (wowace.com/projects/bartender4 and github.com/Nevcairiel/Bartender4). Others are library documentation comments and TOC `X-Website` fields, which are not shown to the player.
- **Text aimed at a reviewer or AI.** None found.

## Concerns
None. I used grep across all Lua files plus targeted reads of the flagged code, and did not read every library file line by line. These are well-known unmodified libraries, and nothing in the greps suggested tampering.
