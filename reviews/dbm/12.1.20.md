# DBM (Deadly Boss Mods) 12.1.20 security review

## What it does
DBM is a boss-encounter addon. It provides timers, warnings, range check, info frames, nameplate auras, voice packs, and raid and keystone info windows. It ships DBM-Core, DBM-GUI, DBM-StatusBarTimers and the raid and dungeon modules, plus the usual embedded libraries (LibStub, CallbackHandler, ChatThrottleLib, LibSharedMedia, LibDropDownMenu, LibKeystone, LibSpecialization and others).

## Risky behaviours checked

- **Gold and item APIs:** I searched all of `builds/` for `SendMail`, `C_Mail`, `TakeInboxMoney`, `PickupPlayerMoney`, `InitiateTrade`, `C_AuctionHouse`, `PlaceAuctionBid`, `StartAuction`, `WithdrawGuildBankMoney` and `DeleteCursorItem`. There were no matches. The addon cannot move gold or items or destroy them.
- **Hidden code:** There were no matches for `loadstring`, `RunScript` or `load(`, and no escaped-byte or obfuscated blobs.
  - The prescan "runs code from strings" hits are only `setfenv(1, lib)` in LibDropDownMenu and `getfenv(0)` in LibSharedMedia. Both are standard library idioms that run no strings.
  - The `_G[...]` hits in `DBT.lua` and the GUI files are lookups of the addon's own frame names or other addons such as Plater.
- **Macros, bindings and logout:** There are no `CreateMacro`, `EditMacro`, `SetBindingMacro` or logout calls.
- **Chat and whispers:** All hits are expected boss-mod features.
  - `AddonComms.lua:211-221` is a `sendWhisper` helper. It is used for the optional status auto-respond during an encounter (`DBM-Core.lua:4222-4244`) and for whisper warnings (`CombatDetection.lua:1346, 1435`). It skips BNet whispers to yourself and does nothing in trial accounts or when restrictions are active.
  - `Commands.lua:48` whispers a raid member, only when the user runs the version check with notify and that member's DBM revision is older than the installed release. The text is `L.YOUR_VERSION_OUTDATED`, which points to deadlybossmods.com (`localization.de.lua:185`, `localization.it.lua:195`). This is the author's own site.
  - `Yell.lua:103-127` sends a SAY or YELL for the user's own boss-ability yell feature.
  - `DBT.lua:1777` is the click-to-announce timer feature. It inserts the text into the chat box if one is open, and otherwise sends it to the group.
- **Addon messages:** These are all for features and carry no personal data.
  - DBM's own prefix (`AddonComms.lua:103-161`) carries sync and version data.
  - A BigWigs-compatible prefix (`AddonComms.lua:204`) is used for version checks.
  - Transcriptor (`CombatDetection.lua:597`) sends encounter-log sync messages.
  - Notes (`Notes.lua:146, 149`) shares raid notes.
  - LibKeystone, LibSpecialization, LibLatency and LibDurability send keystone, spec, latency and durability data to group or guild. Those libraries are standard and widely shared.
  - Nothing reports gold, character lists or account names.
  - `BNSendGameData` (`AddonComms.lua:187`) sends sync data to online Battle.net friends on the same realm. The payload is only the DBM sync prefix and message.
- **Links and phishing:** All URLs are the author's own (deadlybossmods.com, the GitHub wiki, allmylinks.com/mysticalos, discord.gg/deadlybossmods) or CurseForge and Wago addon pages. `ShowUpdateReminder` (`UpdateReminder.lua:90-96`) shows the URL in a copy-only edit box. It does not open a browser. `tools/GenerateEncounterLocales.lua` is a developer tool that cannot run inside WoW.
- **Non-addon files:** I found no executables or scripts (`.exe`, `.dll`, `.sh`, `.bat`, `.ps1`, `.py`, `.js` and similar).
- **Embedded instructions:** I found no text aimed at an AI or reviewer.

## Concerns
None. I did not open every line of the large boss-module and localization files. I searched them for the dangerous APIs and for encoded blobs, and found none.

VERDICT: PASS

## Codex

DBM provides boss warnings, timers, encounter synchronization, and raid-readiness tools. **No malicious behavior was established in the code examined, but this review is incomplete:** I did not finish reading all 188 Lua files under `builds/`, so I cannot approve the release.

Paths below are relative to `builds/DBM-Core-12.1.20/`.

- **Gold, items, and destructive actions:** Searches found no mail transfers, trading or auction transactions, item destruction, key-binding changes, or logout calls. This is search evidence, not a completed whole-source assurance.
- **Chat and whispers:** `DBM-Core/modules/objects/Yell.lua:103–127` sends configurable encounter warnings. `DBM-Core/DBM-Core.lua:4195–4249` implements combat-status replies to friends/guildmates, controlled by `AutoRespond`; combat-end follow-ups go to those correspondents (`modules/CombatDetection.lua:1346,1435`). Version reminders require `/dbm ver2` (`modules/Commands.lua:48,147`). Timer announcements use the bar’s interaction handler (`DBM-StatusBarTimers/DBT.lua:352,1777`). These examined paths serve addon features.
- **Addon messages and privacy:** `modules/AddonComms.lua:103–204` handles group/guild synchronization and optional world-boss sharing with Battle.net friends. The bundled libraries transmit durability, latency, specialization/talents, and keystone/rating data. `modules/gui/RaidChecks.lua:826,2121,2167` shares consumable and equipment summaries; `modules/Notes.lua:129–149` shares notes through a button. `modules/CombatDetection.lua:597` forwards NPC boss whispers for encounter logging. No gold or account-name exfiltration was found in these paths. Auto-replies and world-boss sharing default to enabled (`modules/objects/CoreOptions.lua:150–152`).
- **Code execution:** The five prescan environment-function hits concern library namespaces, including `"setfenv(1,lib)"` (`LibDropDownMenu.lua:56`). Profile imports decode CBOR data (`DBM-GUI/DBM-GUI.lua:291–300`). An additional generated `"/run ChatFrame_SendTell(...)"` button opens whisper composition for a game-provided character name (`modules/gui/Keystones.lua:352`); it does not automatically send a message.
- **Links and packaged files:** Examined links concern DBM, its author, addon downloads, documentation, or XML schemas. No account-support phishing was identified. The standalone `DBM-Core/tools/GenerateEncounterLocales.lua:55` invokes `"curl"` to download encounter-name CSV data; it is absent from addon load manifests and appears to be a development utility. Audio/texture signatures matched their extensions.
- **Reviewer-directed text:** Searches found no instructions addressed to this reviewer or an AI reviewer.

**Outstanding concern:** The remaining source needs review before Packmule treats this release as trusted.

VERDICT: UNSURE (something needs a human to look)
